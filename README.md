# VeriGate AI-SDLC (`verigate-sdlc`)

Vendor-neutral, zero-dependency **6-Stage Deterministic AI-SDLC Framework** that any developer or engineering team can drop into **any project** and run identically across **all LLMs, coding agents, IDEs, and CI pipelines**.

---

## Supported LLMs & Coding Surfaces Out of the Box

| AI / Engineering Surface | Native Files Generated by `install_verigate.py` | Deterministic Hook Enforcement |
| :--- | :--- | :--- |
| **Google Antigravity & Gemini CLI** | `GEMINI.md`, `AGENTS.md`, `.agents/hooks.json`, `.agents/skills/*` | Native `PreInvocation`, `PreToolUse`, `PostToolUse`, `Stop` |
| **Claude Code** | `CLAUDE.md`, `.claude/settings.json`, `.claude/agents/*`, `.claude/skills/*` | Native `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Stop` |
| **OpenAI Codex** | `AGENTS.md`, `.agents/skills/*` | `AGENTS.md` + Git `pre-commit` + CI Gate |
| **Cursor & Windsurf** | `.cursor/rules/verigate.mdc`, `.windsurfrules`, `AGENTS.md` | Always-on `.mdc` rule + Git `pre-commit` + CI Gate |
| **GitHub Copilot** | `.github/copilot-instructions.md`, `.github/workflows/verigate-gate.yml` | Copilot instructions + GitHub Actions SHA-256 PR Gate |
| **Any Chat / Local LLM (Ollama, ChatGPT, DeepSeek, etc.)** | `.githooks/pre-commit`, `.sdlc/bin/verigate.py`, `.sdlc/bin/issue_bridge.py` | Git `pre-commit` blocks unapproved specs & secrets automatically |

---

## Quick Start (Drop Into Any New or Existing Repository)

```bash
git clone https://github.com/apatilai/verigate-sdlc.git
python3 verigate-sdlc/install_verigate.py \
  --target /path/to/your-project \
  --targets all \
  --activate-git-hooks
```

---

## Core Portable CLI Commands (`.sdlc/bin/`)

```bash
# 1. Print 6-stage agent dispatch plan for any prompt
python3 .sdlc/bin/verigate.py dispatch "Build a multi-tenant billing API"

# 2. Validate & approve .sdlc/intent.md + .sdlc/spec.md SHA-256 content hashes
python3 .sdlc/bin/verigate.py validate --project .
python3 .sdlc/bin/verigate.py approve --project . --stage S1_S2 --approver "tech-lead"

# 3. Record a logged Stop/Test waiver when a tool or environment is unavailable
python3 .sdlc/bin/verigate.py waive --project . --stage S4_TEST --reason "Database container offline"

# 4. Preview or create GitHub Issues / Azure DevOps Work Items from .sdlc/review-findings.json
python3 .sdlc/bin/issue_bridge.py detect --repo .
python3 .sdlc/bin/issue_bridge.py preview --findings .sdlc/review-findings.json --provider auto
python3 .sdlc/bin/issue_bridge.py create --findings .sdlc/review-findings.json --provider auto --min-severity High
```
